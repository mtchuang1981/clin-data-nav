# 治理文件就緒檢查表

本公開檢查表僅用來準備外部治理文件的參照代碼。請勿把被參照的資料或
已填妥的真實個案放進本儲存庫。

| 控制項 ID | 外部必備文件證據 | 負責角色 | 尚未備妥時禁止進行的行動 |
|---|---|---|---|
| `study-owner-role` | 已記錄的研究歸責與升級處理管道 | 研究負責角色 | 不得送審、招募或轉移最終責任。 |
| `institutional-path-request` | 已提出由機構判定適用審查路徑的正式請求 | 機構審查角色 | 不得自行假定不需審查或審查已完成。 |
| `scope-risk-benefit` | 可供機構審查的範圍、預定用途、可預見風險與預期效益 | 研究負責角色 | 不得宣稱研究已獲機構接受。 |
| `external-storage` | 經核定的外部儲存位置與處理紀錄 | 資料保管角色 | 不得把真實個案或研究資料放入 Git。 |
| `access-minimization` | 依角色控管的存取名單與最小權限理由 | 隱私或資安負責角色 | 不得授予文件未記錄角色額外權限。 |
| `retention-deletion` | 保存期間、刪除觸發條件與負責角色 | 資料保管角色 | 不得在缺乏文件規則時保留資料。 |
| `consent-material` | 機構判定結果及受控的參與者文件組（如適用） | 機構審查角色 | 不得接觸或納入任何人。 |
| `recruitment-plan` | 可供機構審查的招募途徑、對象邊界與停止條件 | 研究協調角色 | 不得宣傳、篩選或招募。 |
| `incident-response` | 事件通報、控制、升級與復原管道 | 隱私或資安負責角色 | 不得在沒有事件處理管道時蒐集資料。 |
| `environment-freeze` | 可重現的環境清單與版本變更停止規則 | 技術環境負責角色 | 不得在未記錄的環境啟動研究工作階段。 |
| `rater-readiness` | 評分角色、訓練證據、校準 gate 與盲性邊界 | 評分負責角色 | 就緒狀態未記錄前，不得評分真人產出。 |
| `task-pack-commitment-plan` | 外部保管、承諾時間點、洩漏處置與後續驗證計畫 | 任務包保管角色 | 不得建立或揭露真實任務包或 nonce。 |

結構完整的檢查表可以是 `ready-for-institutional-review`，但一律仍是
`not-authorized-to-recruit`。本檢查表不選擇、也不判定倫理審查路徑。
