# 效果評估先導研究彙總報告模板

本模板不包含任何結果。只能使用通過驗證的彙總摘要填寫。無論結果為正向、
負向或中性，皆須使用相同標題、分母、精確度、安全性分開呈現方式與限制。

## 摘要

說明產品評估的彙總發現、探索性質、合成任務邊界，以及先導研究不能證明
臨床效度。

## 方法

報告研究規格 commit、研究日期、模型／Skill 環境、分派版本、任務承諾
驗證狀態，以及參與者叢集 bootstrap 設定。
品質準則屬於次要結果，絕不決定主要任務成功；適用分母為零時無法估計。

## 參與者流程

報告分派與完成人數、兩個分層、未完成任務事件、主要分析完整配對數，
以及解讀狀態。

## 主要結果

報告兩個條件的分母與比率、介入減對照的配對風險差、95% 區間、配對分布，
以及絕對 20 個百分點的最小實務差異。

## 分層結果

分別報告初學者與專業者的彙總結果，不宣稱分層間比較具有確認性檢定力。

## 安全性

分條件報告重大事件數、分母、比率與精確 95% 區間。不得以品質或速度
抵銷安全事件。

## 次要結果

報告配對時間、品質、NASA-TLX、信心與理解程度；介入條件 SUS；逾時與
技術失敗率；以及準則彙總結果。

## 評分者一致性

報告原始裁定前的二元與序位原始一致率、Cohen kappa、線性加權 kappa、
重大事件歧見、裁定次數與解盲狀態。

## 缺失資料與敏感度分析

報告完整案例與預先指定保守缺失值分析的分母及估計值。

## 樣本數情境

報告所有保守情境。在另行核准的先導研究後分析完成前，顯示
`deferred-until-post-pilot` 與 JSON null 樣本數；不得用先導研究點估計
虛構檢定力結果。

## 規格偏離

依預先指定類別報告零項或所有彙總規格偏離。

## 限制

報告所有重大限制，並維持產品效果與臨床效度之間的界線。

## 欄位字典

| 欄位 | 意義 |
|---|---|
| `protocol_commit` | 研究使用的版本化研究規格實作 |
| `environment` | 固定模型、Skill、平台、日期、任務承諾與 bootstrap 設定 |
| `participant_flow` | 彙總分派、完成情形、缺失與解讀狀態 |
| `primary` | 通過安全門檻的配對任務成功彙總與敏感度分析 |
| `safety` | 分條件重大事件數、比率與精確區間 |
| `secondary` | 配對連續結果、SUS、失敗與準則彙總 |
| `agreement` | 原始裁定前一致性與解盲前狀態 |
| `power_scenarios` | 預先指定保守輸入與延後／已計算狀態 |
| `protocol_deviations` | 僅限彙總規格偏離 |
| `limitations` | 重大解讀與可推廣性限制 |
