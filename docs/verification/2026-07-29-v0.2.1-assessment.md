# v0.2.1 Assessment Revalidation

Date: 2026-07-29

## Decision

The local `v0.2.2` remediation candidate fixes the reproducible public-build
and documentation findings confirmed against the published `v0.2.1`
baseline. Fresh editable installation and all four acceptance commands pass
on disposable Windows and Linux Python 3.11 environments.

This is local evidence only. It does not claim that GitHub Actions is green,
that either workflow is registered at the candidate commit, or that branch
protection enforces the matrix. Those external checks remain gated on the
separately approved Task 11 push. No tag or GitHub Release was created or
modified by this validation.

uninstalled. Every remaining installer, installation, venv, and isolated-test
temporary directory was checked by exact parent and fixed prefix before
removal. `PATH` was unchanged, and `py -0p` again listed only the original
Python 3.13 runtime.

- runtime: `Python 3.11.15`;
- Debian Git: `2.47.3`.

The bare slim image does not include Git, while 32 repository tests exercise
real Git repositories. The exact first container command therefore produced
`182 passed, 32 failed, 2 warnings in 5.33s`; all 32 failures had the same
root cause, `FileNotFoundError: git`. After the approved minimal installation
of Debian's `--no-install-recommends git`, the direct Windows worktree mount
produced `213 passed, 1 failed, 2 warnings in 5.93s`. Its only failure was the
acceptance check because the worktree `.git` file contains a Windows `E:/...`
gitdir that Linux cannot resolve.

The corrected clean-room run did not copy untracked files or reuse Git
environment redirects. It:

1. created `candidate.tar` with `git archive HEAD`, so only tracked candidate
   files were included;
2. mounted that archive read-only in a disposable `python:3.11-slim`
   container;
3. installed Debian's minimal Git package;
4. extracted the archive into the container, initialized `main`, and created
   one synthetic commit;
5. ran the same editable install and four-command acceptance set.

`24241cf9ffaba3d5b0e2a84ddc649f8f0b936135e84bd051c3575964914dce6d`.
