# OMOP 1.1 DuckDB limitation: local integration verification

## Scope

This change integrates the existing opt-in OMOP metadata contract 1.1 and adds
`duckdb-cyclic-fk-ddl-limited` only to 1.1's controlled limitation codes.
The code is an explicit adapter attestation, not a checker-inferred or
independently verified backend diagnosis. The 1.0 default and its accepted
codes, structural decisions and checker exit codes remain unchanged.

The database-declared FK verdict, DQD point-in-time evidence status, and study
fitness are separate. A synthetic summary with 13 missing table-level FK
statuses, accepted DQD attestation and this code remains `incompatible`, exit 3.
The code cannot repair missing/stale/failed evidence or an incomplete scan.
