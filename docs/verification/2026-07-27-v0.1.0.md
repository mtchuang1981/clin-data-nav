### Authorized second safety-fix round

The first final attack review found two remaining release blockers:

1. the no-overwrite installer exposed an empty reservation and then trusted a
   pathname-based inode check, allowing a pathname swap to redirect writes or
   cleanup into a competing directory;
2. the validator allowed an existing
   `references/../../outside.md` backtick reference to escape the Skill root.

The user explicitly authorized one additional safety-fix round limited to
these two findings.

1. Initial RED reproduced both defects: `2 failed`. The installer test showed
   `SKILL.md` and `agents/` written into the substituted competitor directory;
   the validator accepted an existing file outside the Skill root.
2. Initial GREEN replaced the visible reservation/per-child move with atomic
   whole-directory no-replace publication and added lexical plus resolved
   reference containment: the focused set passed `8 passed`.
3. Independent review accepted Linux `renameat2(RENAME_NOREPLACE)` but found
   Darwin portability and five backtick candidate-extraction bypasses.
   Reviewer-derived RED was `6 failed`; GREEN added Darwin
   `renamex_np(RENAME_EXCL)` and portable path candidate handling.
4. Re-review identified three remaining Windows root/case variants. They
   reproduced as `3 failed, 5 passed`. The final candidate filter sends every
   slash/backslash or Windows-drive backtick token through lexical and resolved
   containment; the focused set then passed `8 passed`.
5. The installer regression now creates a competitor immediately before the
   real native publish call and verifies that the competitor inode remains
   unchanged. Missing Linux/Darwin primitives and unsupported platforms fail
   closed with `ENOTSUP`.
6. Final independent safety re-review reported no Critical, Important, or
   Minor findings and assessed the authorized fixes as ready.
7. Full GREEN after the final reviewed commit: `152 passed`.
