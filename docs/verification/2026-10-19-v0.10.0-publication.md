## Preserved failures, risk acceptance and process deviation

The first feature-dispatch run
[39210715168](https://github.com/mtchuang1981/clin-data-nav/actions/runs/39210715168)
failed on both platforms at the default-main acceptance assertion. Fresh
feature checkouts lacked `origin/HEAD`; the gate was not relaxed. A small
validate-workflow setup now queries the actual remote default with
`git remote set-head origin --auto`. Two synthetic RED-to-GREEN integration
tests consume that command, accepting actual main and still rejecting an
actual remote default of release. The corrected new-commit run passed; the
original failed run was not erased or rerun unchanged.

Separately, the earlier intermittent Windows cleanup anomaly remains
unexplained and is **not claimed fixed**. The user explicitly accepted that
known risk on 2026-10-19, conditional on every fresh local, main CI,
cross-platform package and CodeQL gate passing. Those gates all passed before
the tag and release dispatch. This acceptance did not waive a new failure.
See the [local candidate record](2026-10-19-governed-compiler-pipeline.md) and
[publication preflight](2026-10-19-v0.10.0-publication-preflight.md).

The normal main push produced a server-side owner-bypass warning:
`3 of 3 required status checks are expected`. This is a process deviation,
not a claim that branch protection was fully enforced. Before that push, the
same SHA had all three isolated workflow-dispatch checks successful, from
GitHub Actions app ID 15368; nevertheless, the server did not credit them as
the required main checks. The precise server selection cause is not established.
No `--force`, admin merge option, protection change or credential workaround
was used. The user was informed immediately; tag/release creation remained
blocked until main's own checks, local full suite and CodeQL all passed.
Subsequent publication-record and installation updates use a normal PR rather
than repeating the direct-push path. Administrative enforcement changes, if
desired, require separate authorization; none were made here.
