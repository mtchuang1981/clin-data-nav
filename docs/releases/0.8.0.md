# Clinical Data Research Navigator v0.8.0

Release date: 2026-09-18

## English

### Auditable evidence records

- Adds a closed JSON evidence ledger and an offline checker. The checker makes
  no network requests and evaluates only the recorded structure and review
  state.
- A source may move beyond `not-reviewed` only after the cited item was
  actually opened and reviewed. A claim remains `not-assessed` until its
  support has been evaluated.
- Unknown dates and versions remain JSON `null`. An unknown stable identifier
  is recorded as `stable_identifier: null`; the ledger does not invent a
  surrogate identifier.
- Claim support uses the explicit states direct, partial, unsupported, and
  not-assessed.
- The checker returns exit code 0 for a structurally valid ledger with no
  recorded review due, exit code 3 for a valid ledger requiring review, and
  exit code 2 for invalid input.

### Output contract

- Carries forward the concise quick-explanation behavior introduced in 0.7.1.
  Evidence navigation, research design, and implementation specifications
  retain their structured contracts and execution boundaries.
- The frozen 72-cell benchmark is not rerun for this release. Its earlier
  result remains unchanged; deterministic tests and packaging gates validate
  this release instead.

### Evidence boundary

- The ledger records what was reviewed and the declared relationship between
  sources and claims. It does not establish that a source is true, that a
  scientific or clinical conclusion is valid, that people benefit, or that
  the Skill is suitable for deployment.
- Unknown institutional schema must still be expressed as a natural-language
  requirement pending confirmation, never as an invented table or field.

## 繁體中文

### 可稽核證據紀錄

- 新增封閉式 JSON evidence ledger 與離線檢查器。檢查器不發出網路
  請求，只評估已記錄的結構與覆核狀態。
- 只有在實際開啟並覆核所引用的資料後，來源才能離開
  `not-reviewed`；主張尚未評估支持程度時維持 `not-assessed`。
- 未知的日期與版本保留為 JSON `null`；未知的穩定識別碼使用 null
  (`stable_identifier: null`)，不自行虛構替代識別碼。
- 主張支持程度明確區分為直接支持、部分支持、不支持與尚未評估。
- 結構有效且沒有已記錄到期覆核時，檢查器回傳結束碼 0；結構有效
  但需覆核時回傳 exit code 3；輸入無效時回傳結束碼 2。

### 輸出契約

- 延續 0.7.1 的快速說明行為：使用不含固定表頭的精簡自然語句。
  證據導覽、研究設計與實作規格仍保留結構化契約與執行界線。
- 本次不重跑 72-cell benchmark。先前結果維持不變；本版改由
  決定性測試與封裝 gates 驗證。

### 證據界線

- Ledger 記錄已覆核事項及來源與主張間的宣告關係，不能證明來源
  內容為真、科學或臨床結論有效、人們可因此受益，或 Skill 適合部署。
- 未知的機構 schema 仍必須以待確認的自然語言需求表達，不得虛構
  資料表或欄位。
