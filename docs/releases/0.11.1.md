# Clinical Data Research Navigator v0.11.1

Release date: 2026-11-16.
Publication requires fresh local verification, Windows/Ubuntu CI, cross-platform
package equality and CodeQL. These notes alone are not proof of publication.

## English

### Changes

- Present an unresolved coordinator consultation as a concise handling decision,
  findings, decisions to confirm and next deliverable. Explicit formal
  specification requests retain the full contract and execution gates.
- Separate dictionary matching, clinical relevance and selection approval.
  Add bounded synonym search, unread-page and site-gap tracking, tool-specific
  argument checks and count/asset/study feasibility distinctions.
- Repair Windows source-installer staging permissions before extraction by
  applying the selected destination DACL to the installer-owned empty staging
  container. Do not alter parent ACLs, ownership or unrelated installations.
  Permission errors stop before replacing the old installation.
- Add a separate seven-scenario synthetic review catalog and native Windows
  ACL regression coverage, preserving frozen benchmarks and historical records.

### Verification and limitations

A small local five-baseline/five-forward orientation probe across two synthetic
prompts observed coordinator briefs instead of formal documents in the forward
samples. It is not a randomized effectiveness study or clinical validation.
No private Adapter, real-data query or human study was tested.

The unrelated intermittent Windows cleanup anomaly remains unexplained and is
not claimed fixed. This known risk was explicitly accepted on 2026-10-19,
conditional on all fresh gates passing; no failing gate is waived.
The permission repair does not prove another account's effective access or
the host-loaded Skill version. Windows DACL tests are platform-specific.
POSIX permissions and existing atomic publication/rollback remain unchanged.

## 繁體中文

### 調整內容

- 初步承辦諮詢先交付處理結論、關鍵發現、待確認決策與下一份產物。
  明確要求正式規格時，維持完整資料契約與執行閘門。
- 分開字典匹配、研究相關性與核准狀態；補上有界限的同義詞搜尋、
  未讀分頁及院區缺口、工具參數檢查，以及計數／影像資產／研究可行性的區分。
- 修正 Windows 原始碼安裝工具：解壓前將目標目錄的 DACL 套用至安裝器
  自有的空暫存容器；不變更父層權限、擁有者或其他安裝。權限準備失敗時，
  在移動既有安裝之前停止。
- 新增七項合成審查情境及原生 Windows 權限回歸測試；歷史 benchmark 不變。
