# Clinical Data Research Navigator v0.7.1

## English

### Output-contract change

Quick explanations use concise natural prose without a fixed header. Formal
evidence, research-design, and implementation contracts remain structured, with
their required evidence, safety, completion, and execution-boundary fields.
Unknown institutional mappings are stated as logical requirements that await
confirmation rather than as SQL or physical-schema placeholders.

### Evaluation boundary

The fixed ZIP comparison observed 18/18 candidate quick-format cells passing and
a 47.46% median paired visible-character reduction, with no observed forbidden
safety violation. The frozen evaluator nevertheless returned
`candidate-not-supported`. Human review identified three formal-response wording
false negatives; it did not rewrite the frozen automated scores. This evidence
supports the narrow output-contract change only under the recorded synthetic
prompts, model, CLI, and run conditions. It does not establish human
effectiveness, clinical validity, or deployment fitness. See the
[aggregate-only verification record](../verification/2026-09-09-v0.7.1-output-contract-candidate.md).

## 繁體中文

### 輸出契約變更

快速說明改用不含固定表頭的精簡自然語句。正式的證據、研究設計與實作契約仍保留結構化格式，
以及必要的證據、安全、完成條件與執行界線欄位。未知的
機構映射改寫為待確認的邏輯需求，不產生 SQL 或實體 schema placeholder。

### 評估界線

固定 ZIP 比較中，候選版快速格式通過 18/18 cells，配對可見字數中位數減少
47.46%，且未觀察到禁止的安全違規。凍結的評估器仍判定
`candidate-not-supported`。人工覆核確認三筆正式回覆的用詞假陰性，但未改寫已凍結的自動分數。
這些證據只支持在已記錄的合成提示、模型、CLI 與執行條件
下採用狹義輸出契約變更；不能建立真人成效、臨床有效性或部署適用性證據。
詳見[僅含彙總資訊的驗證紀錄](../verification/2026-09-09-v0.7.1-output-contract-candidate.md)。
