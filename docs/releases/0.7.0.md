# Clinical Data Research Navigator v0.7.0 candidate

Candidate notes for the local v0.7.0 release candidate. These are not
published Release notes.

## English

### Candidate improvements

- Mixed-cue requests now route by the primary deliverable instead of isolated
  words such as code or optimization. This covers implementation-literature
  review, cited public profiles, phenotype design, optional causal handoff, and
  settled implementation specifications.
- Every output depth has positive completion slots for the evidence, design,
  data-contract, validation, and execution-boundary fields that apply.
- The deterministic evaluator now treats only another depth's reserved
  headings as cross-depth headings. Useful auxiliary headings do not fail a
  response merely because they are not on an allowlist.
- Required and forbidden rules accept tested semantic equivalents and safe
  negated boundaries while preserving rejection of affirmative causal-effect
  validation and complete-SAP delivery claims.

### Evidence boundary

The latest immutable published Release remains v0.6.0. No v0.7.0 tag or GitHub
Release exists at candidate preparation time. The prior normative 72-cell
simulation campaign remains `mixed-or-null`. A small development preflight is
non-normative and cannot replace a campaign bound to immutable published
artifacts.

No representative user performed a usability task, and no human pilot was
completed. This candidate does not establish human effectiveness, clinical or
causal validity, patient benefit, or deployment fitness.

## 繁體中文

### 候選改善

- 混合提示現在依主要交付物判斷路由，不再被「程式碼」或「最佳化」等單一詞彙
  帶往錯誤深度；涵蓋實作文獻檢視、附引用的公開資料概覽、表型設計、選配因果
  交接，以及已有確定證據的實作規格。
- 每種輸出深度都有正向完成欄位，用來補齊適用的證據、研究設計、資料契約、
  驗證與執行界線。
- 決定性評估器現在只把其他深度的保留標題視為跨深度標題；有助於理解的一般
  輔助標題不會只因未列入允許清單就造成失敗。
- 必要與禁止規則可接受已測試的語意等價說法及安全否定句，同時保留對「因果
  效果已驗證」與「完整 SAP 已交付」等肯定主張的攔截。

### 證據界線

最新的不可變正式發布仍是 v0.6.0。候選版本準備時尚無 v0.7.0 tag 或 GitHub
Release。前一輪規範性 72-cell 模擬活動仍為混合或無明顯差異
（`mixed-or-null`）。小型開發預檢並非規範性活動，也不能取代綁定不可變已發布
產物的正式活動。

目前沒有具代表性的使用者完成可用性任務，也未完成真人先導研究。此候選版本
不能建立真人有效性、臨床或因果有效性、病人效益或部署適用性證據。
