# Clinical Data Research Navigator v0.9.0

Release date: 2026-10-04

## English

### Release capabilities

- Optional read-only OMOP CDM v5.4 metadata navigation: a pinned public catalog,
  adapter capability checks, redacted contract 1.0 summaries, and an offline
  compatibility checker. No private schema, patient rows, or executable
  institutional SQL are bundled.
- An opt-in offline companion evidence audit binds to the canonical ledger
  SHA-256 and checks recorded source access, version review, per-source
  citation locators, and claim-fit review. It makes no network requests and
  preserves ledger schema 1 and the existing ledger checker's exit codes.
- Optional read-only installed-Skill verification uses an explicitly trusted
  external manifest. Byte identity and canonical-text content matches remain
  different results; the tool does not install, overwrite, or restart a host.
- Formal validation gaps identify what is blocked, the next safe action, the
  responsible role, and acceptable completion evidence. Quick explanations
  remain concise, and formal outputs retain their execution boundaries.
- Aligned synthetic examples and bilingual community feedback forms make safe
  use and reporting easier without requesting raw responses or private data.

### Safety and publication

- Public-boundary scans now require the physical Git root to match the scanned
  root, failing closed on ancestor fallback and redirected worktrees.
- Strict bounded JSON, public audit URL validation, content-free OMOP failure
  summaries, and shared narrow package checks retain fail-closed behavior.
- Release dispatch is allowed only from main. Jobs executing repository code
  check out the immutable dispatch SHA, not the tag input. Publication uses
  the verified artifact bundle without checking out or executing repository
  code in the writer job.
- Ubuntu and Windows package candidates must be byte-identical before
  publication. The public ZIP and manifest can be independently verified
  with the existing release verifier and SHA-256 checks.

### Evidence boundary

- Recorded audit completion does not independently verify source truth,
  freshness, or semantic support. A reviewer must actually consult and assess
  the sources; the offline checker validates the recorded contract.
- Metadata compatibility does not grant data access or analysis authority,
  establish data quality or scientific validity, or make a specification
  executable. Unknown institutional mappings remain natural-language
  requirements pending confirmation.
- Installed-file matches cover only the selected manifest's files:
  `loaded_version: not-verified` remains explicit.
- This release does not include OMOP contract 1.1 or private-adapter validation.
  It does not rerun or reinterpret the historical 72-cell benchmark or the
  evidence-ledger pilot, whose `pilot-failed` result remains unchanged.
- Deterministic tests and packaging gates do not establish human
  effectiveness, clinical validity, causal validity, or deployment fitness.

## 繁體中文

### 發布功能

- 選用的唯讀 OMOP CDM v5.4 metadata 導覽：包含鎖定版本的公開
  catalog、adapter 能力檢查、遮蔽摘要契約 1.0 與離線相容性檢查器。
  套件不含私有 schema、病人資料列或可執行的機構 SQL。
- 明確選用的離線 companion evidence audit，以 canonical ledger
  的 SHA-256 強綁定紀錄，檢查已記錄的來源存取、版本覆核、逐來源
  引用位置及主張支持程度審閱。不發出網路請求，保留 ledger
  schema 1 與既有 ledger checker 的結束碼。
- 選用的唯讀 Skill 安裝完整性診斷，使用明確信任的外部 manifest。
  逐位元組相同與 canonical-text 內容相符是不同結果；工具不安裝、
  覆寫或重啟 host。
- 正式驗證缺口明列阻擋事項、安全下一步、責任角色及可接受的完成
  證據。快速說明維持精簡，正式輸出保留既有執行界線。
- 對齊合成範例，提供雙語社群回饋表單；不要求原始回答或私有資料。

### 安全性與發布

- 公開邊界掃描要求實體 Git 根目錄等於掃描根目錄；找到祖先
  repository 或被重新導向的 worktree 時，遇到不一致即停止。
- 限額嚴格 JSON、公開 audit URL、不回顯內容的 OMOP 失敗摘要及
  狹窄共用套件檢查，延續遇到不一致就停止的行為。
- Release 只能從 main dispatch。執行 repository code 的 jobs
  checkout 不可變的 dispatch SHA，不使用 tag input 選取程式碼；
  最終 writer job 只發布已核對的 artifact bundle，不 checkout
  或執行 repository code。
- Ubuntu 與 Windows 候選套件必須逐位元組相同才能發布。公開 ZIP
  與 manifest 可透過既有 release verifier 和 SHA-256 獨立核對。

### 證據界線

- Audit 紀錄完成不等於獨立證明來源真實、新鮮度或語意支持程度。
  審閱者仍須實際查閱與評估來源；離線 checker 只驗證紀錄契約。
- Metadata 相容不授予資料存取或分析權限，也不證明資料品質、
  科學有效性，或讓規格變成可執行。未知機構映射仍以待確認的
  自然語言需求表達。
- 安裝檔案相符只涵蓋指定 manifest 的檔案範圍，仍明示
  `loaded_version: not-verified`。
- 本版不包含 OMOP 契約 1.1 或私有 adapter 驗證。不重跑或重新解讀
  歷史 72-cell benchmark 與 evidence-ledger pilot；後者的
  `pilot-failed` 結果維持不變。
- 決定性測試與封裝 gates 不能建立真人成效、臨床有效性、
  因果有效性或部署適用性證據。
