# Clinical Data Research Navigator v0.3.0

## English

### Highlights

- Four output depths—quick explanation, evidence navigation, research design,
  and implementation specification—let the Skill choose the least intensive
  safe response that fully answers the request.
- Beginner navigation now includes a compact first-success flow, bilingual
  glossaries, three guided learning paths, and stage-specific installation
  troubleshooting.
- The offline Eval evidence contains 12 baseline/forward fixture pairs. All
  four output depths have deterministic regression-contract coverage.
- The validation and guarded Release workflows build candidates on Ubuntu and
  Windows and require byte-identical ZIP and manifest files before proceeding.
- Citation, Skill UI, security, product-boundary, and repository-setting
  metadata are clearer and remain limited to verifiable repository facts.

### Installation

Install the Agent Skill in the current project:

```bash
npx skills add mtchuang1981/clin-data-nav
```

For a pinned asset installation, use both
`clinical-data-research-navigator-0.3.0.zip` and
`clinical-data-research-navigator-0.3.0.manifest.json` from the same Release.
Verify the ZIP's SHA-256 against the manifest's `archive_sha256` value before
extracting it.

### Verification

The repository contract includes the complete pytest suite, Skill validation,
the public-boundary scan, and the reproducible-package check. The deterministic
packager records the archive SHA-256 and every packaged file hash in the
manifest. Cross-runner comparison rejects missing, extra, renamed, nested, or
byte-mismatched package files.

### Limitations

Deterministic Evals verify repository response contracts; they do not prove
source accuracy, clinical validity, causal validity, or complete real-world
coverage. The public Skill contains no private institutional schema or
metadata. Executable institutional work still requires an approved Adapter,
current metadata, parameters, fixtures, and review in the governed
environment.

- 引用、Skill UI、安全性、產品界線與儲存庫設定等詮釋資料更清楚，內容仍

### 安裝

在目前專案安裝 Agent Skill：

```bash
npx skills add mtchuang1981/clin-data-nav
```

若要固定資產版本，請使用同一個 Release 中的
`clinical-data-research-navigator-0.3.0.zip` 與

### 驗證

儲存庫契約包含完整 pytest 測試、Skill 驗證、公開邊界掃描與可重現封裝
檢查。確定性封裝器會把 archive SHA-256 與每個封裝檔案的雜湊寫入
manifest。跨 runner 比對會拒絕遺漏、多餘、改名、巢狀或位元組不一致的
套件檔案。

### 限制

確定性 Eval 只驗證儲存庫的回覆契約，不能證明來源正確、臨床效度、因果
效度或真實世界情境已完整涵蓋。公開 Skill 不包含私有機構 schema 或
詮釋資料；機構內可執行工作仍需要經核准的 Adapter、現行詮釋資料、參數、
fixture，以及受治理環境中的審閱。
