## English

### Changes

- Review 42 current public Markdown guidance files with STE-inspired principles.
  Split complex instructions, put conditions first and clarify responsible actors.
  Apply the same clarity principles to Traditional Chinese, without English word-count limits.
- Preserve modal force, authorization, stop rules, technical vocabulary, fixed
  output labels and executable examples. Retain clear passages rather than rewrite them mechanically.
- Include the explicit opt-in `research-bilingual-v1` heading contract added after
  v0.10.0. Its five exact English/Traditional Chinese heading pairs do not replace
  the default `legacy-v1` or change content, scoring and safety requirements.
- Keep historical records, catalogs, fixtures and generated reports unchanged.
  The UI metadata and public/private boundary remain unchanged.

### Verification and limitations

This is an STE-inspired language review, not formal ASD-STE100 certification.
Deterministic tests and reproducible packaging do not prove model performance,
human usability, clinical validity, source truth or token savings.
No new model campaign, private-adapter test or human study is part of this release.

The previous intermittent Windows cleanup failure remains unexplained and is
not claimed fixed. The user explicitly accepted this known risk for publication
on 2026-10-19, conditional on all fresh gates passing. No failing gate is waived.
