# Clinical Data Research Navigator v0.5.0

Candidate release notes. No `v0.5.0` tag or GitHub Release is claimed, and
publication remains a separately authorized action.

## English

### Installation

Install the repository into the current project:

```bash
npx skills add mtchuang1981/clin-data-nav
```

Confirm `.agents/skills/clin-nav/SKILL.md`, inspect `/skills`, and invoke
`$clin-nav`.

### Migration

Inspect the exact existing
`.agents/skills/clinical-data-research-navigator` directory before removing or
archiving anything. Remove or archive only that verified directory with a safe
platform file operation, never a broad or unresolved path, then rerun the
installation command and verify the new `clin-nav` directory.

### Limitations

The rename does not establish human effectiveness. The separate
effectiveness-recovery implementation remains pending, and no replacement human pilot has reached green.
Clinical routing and safety behavior are
preserved; no recovery capability is claimed.

### Verification

The candidate requires the full test suite, repository gates, reproducible
package check, independent ZIP and manifest verification, official Python
3.11.9 checks, and an isolated local-source install smoke before handoff.
