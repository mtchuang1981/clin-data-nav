## English

### Installation

Install the repository into the current project:

```bash
npx skills add mtchuang1981/clin-data-nav
```

Confirm `.agents/skills/clin-nav/SKILL.md`, inspect `/skills`, and invoke
`$clin-nav`.

### Migration

Inspect the exact existing
`.agents/skills/clinical-data-research-navigator` directory before removing or
archiving anything. Remove or archive only that verified directory with a safe
platform file operation, never a broad or unresolved path. Move any archive
outside `.agents/skills` and every other Skill discovery root. Then rerun the
installation command and verify the new directory. Use `/skills` to confirm
`clinical-data-research-navigator` is absent and `clin-nav` is the only
installed entry for this Skill.

### Limitations

The rename does not establish human effectiveness. This candidate includes a
green-capable effectiveness-recovery contract with six deterministic states
and four content-free stage commands; the affected batch remains
`excluded-from-effectiveness-analysis`. No real replacement pilot was performed; observed `evaluation-green` remains pending; power analysis remains deferred; and no tag or GitHub Release is created by this recovery plan.

### Verification

The candidate requires the full test suite, repository gates, reproducible
package check, independent ZIP and manifest verification, official Python
3.11.9 checks, and an isolated local-source install smoke before handoff.
