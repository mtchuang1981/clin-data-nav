# Clinical Data Research Navigator v0.11.2

Candidate prepared: 2026-11-22. GitHub records the publication date upon release.

## English

### Changes

- Strengthen synthetic output cleanup tests for Windows, same-process rollback,
  subprocess cleanup and POSIX cases by checking file identity. The assertions
  can detect retained owned files after renames and in cases involving hard links.
- Record completed public checks and update installation guidance for verifying
  the public Release artifacts. The installable Skill content is unchanged.

### Verification and limitations

The cleanup tests use synthetic data. The root cause of the intermittent
Windows cleanup anomaly remains unexplained. Private institutional acceptance
and human usability and effectiveness evaluation remain pending.

### 調整內容

私有機構端驗收與真人易用性及成效評估仍保留待辦。
