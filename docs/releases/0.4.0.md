# Clinical Data Research Navigator v0.4.0

## English

### Highlights

- Add a human-effectiveness evaluation framework with strict synthetic-data
  contracts for balanced assignments, task-pack commitment, blinded agreement
  and unlock safeguards, paired analysis, controlled deviations and
  limitations, and aggregate-only bilingual reports.
- Preserve PICO, RWD, RWE, and target trial emulation (TTE) documentation
  continuity, including the protocol, input schema, quick start, and public
  repository boundaries.
- Add canonical LF checkout enforcement for deterministic packages and
  transactional recovery for bilingual report publication.

### Installation

Install the Agent Skill in the current project:

```bash
npx skills add mtchuang1981/clin-data-nav
```

For a pinned installation, download both
`clinical-data-research-navigator-0.4.0.zip` and
`clinical-data-research-navigator-0.4.0.manifest.json` from the same Release.

### Verification

Use the same-Release manifest to verify the ZIP SHA-256 against its
`archive_sha256` value before extracting it. The package and framework
contracts are verified with Python 3.11.9 and deterministic cross-platform
checks.

### Limitations

The evaluation framework is available, but no human pilot was conducted and
the Skill is not proven effective. All examples and reports are synthetic and
aggregate-only. This release does not include human participant data, private
institutional metadata, or executable institutional workflows.
