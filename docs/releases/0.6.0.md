# Clinical Data Research Navigator v0.6.0 candidate

Candidate notes for the local v0.6.0 capability. These are not published
Release notes.

## English

### Candidate capabilities

- A provider-neutral public simulation benchmark freezes all 12 public Eval
  cases across control and intervention conditions for three repeats, yielding
  a complete 72-cell plan.
- The first normative campaign binds the exact released v0.5.0 Skill bundle;
  the intervention adds that bundle and `$clin-nav` while shared model and
  runner settings remain fixed.
- Evaluation reuses the existing deterministic evaluator and produces paired,
  reproducible aggregates and aligned English and Traditional Chinese reports.
- The structured Issue Forms collect privacy-warned, community-reported aggregate
  observations without adding them to formal benchmark results.

### Evidence boundary

Plans, response indexes, raw responses, provider logs, and generated real-run
reports stay outside the repository. CI does not call a model or accept model
credentials. The repository contains only public contracts and explicitly
synthetic examples.

There is no v0.6.0 tag or GitHub Release. No real benchmark campaign or human
pilot has been performed. The synthetic examples demonstrate software
contracts only; they do not establish usability, clinical or causal validity,
patient benefit, or deployment fitness.

The candidate local installer and packager are synchronized at v0.6.0, but
these are release-preparation tools rather than published installation
surfaces. The latest immutable published bundle remains v0.5.0.

## 繁體中文

### 候選功能

- 供應商中立的公開模擬基準會固定全部 12 個公開 Eval 案例，分成 control
  與 intervention 兩種條件並各重複三次，形成完整的 72-cell 計畫。
- 第一次規範性活動綁定確切且已發布的 v0.5.0 Skill 套件；intervention
  僅加入該套件與 `$clin-nav`，共用的模型及 runner 設定維持不變。
- 評估沿用既有的決定性評估器，產生可重現的配對彙總，以及對齊的英文與
  繁體中文報告。
- 結構化 Issue Forms 收集附帶隱私警語、由社群自行回報的彙總觀察，且不會
  將這些回報加入正式基準結果。

### 證據界線

計畫、回覆索引、原始回覆、供應商紀錄及真實執行所產生的報告都留在
儲存庫外部。CI 不會呼叫模型，也不接受模型憑證。儲存庫只包含公開契約與
明確標示的合成範例。

目前沒有 v0.6.0 tag 或 GitHub Release。尚未執行真實基準活動或真人先導研究。
合成範例只示範軟體契約，不能建立可用性、臨床或因果有效性、病人
效益或部署適用性的證據。

候選本機安裝程式與封裝程式已同步為 v0.6.0，但兩者都是正式發布前的準備
工具，不是已發布的安裝介面。目前最新的不可變正式發布套件仍是 v0.5.0。
