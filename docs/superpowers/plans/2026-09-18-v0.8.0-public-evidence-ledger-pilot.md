> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Run a four-case public-source audit of the immutable v0.8.0 evidence-ledger workflow and preserve only aggregate, non-sensitive verification evidence in Git.

**Spec:** `docs/superpowers/specs/2026-09-18-v0.8.0-public-evidence-ledger-pilot-design.md`

### Task 5: Apply the Frozen Rubric and Classify the Pilot

**Files:**
- Create externally: `aggregate-report.md`

**Interfaces:**
- Consumes: all four complete case records.
- Produces: one traceable aggregate decision.

- [ ] **Step 1: Verify checker parity and frozen exits**

For every case require packaged exit equals repository exit, packaged canonical JSON equals repository canonical JSON, and actual exit equals frozen exit. Checker disagreement or exit `2` is `pilot-failed`. Preserve any mismatch.

- [ ] **Step 2: Evaluate all twelve claim rows**

Require every claim to be present. Require verified locators for `direct-support` and `partial-support`, `authority_fit = appropriate`, and `support_fit = appropriate` or an honestly unresolved `not-assessed`. An omitted claim, fabricated locator, or `overstated` result is critical.

- [ ] **Step 3: Evaluate all four negative conditions**

Require:

```text
CDISC development material was not promoted to current final
OMOP historical documentation was not promoted to current
TTE was not treated as proof of valid causal inference
Lex Jansen material was not promoted to official authority
```

Any failure is critical.

- [ ] **Step 4: Apply the exact decision order**

```text
critical violation or checker parity failure -> pilot-failed
frozen checker-exit mismatch -> pilot-failed
freshness/authority meaning depends on companion audit or remains ambiguous -> pilot-mixed
otherwise -> pilot-supported
```

Do not upgrade a mixed result merely because the companion audit supplies information absent from the v0.8.0 ledger.

- [ ] **Step 5: Write the external report**

Include immutable release identity, plan hash, per-case checker parity/exits, twelve claim outcomes, four negative-condition outcomes, native-versus-companion findings, critical-violation count, one decision, and the exact claim boundary. Exclude long quotations and scientific-validity claims.
