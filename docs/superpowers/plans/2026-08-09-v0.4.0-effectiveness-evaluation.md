**Goal:** Build a repository-native, privacy-preserving effectiveness evaluation kit that supports a reproducible offline dry run and a separately authorized 16-person balanced crossover pilot without claiming clinical validity.

**Architecture:** Keep the new effectiveness layer independent from the existing deterministic response-contract Evals. Use versioned YAML/JSON contracts, a deterministic assignment generator, an external human-task commitment, a two-file blinded unlock, standard-library paired statistics, and bilingual aggregate reports; raw human answers and participant rows never enter the repository.

PRIVATE_EFFECTIVENESS_PARTS = {"raw", "private", "participant-data"}


def _is_private_study_path(relative_path: Path) -> bool:
    if any(
        relative_path == root or root in relative_path.parents
        for root in PRIVATE_STUDY_ROOTS

    effectiveness = Path("evals/effectiveness")

    return bool(remainder.parts) and remainder.parts[0] in PRIVATE_EFFECTIVENESS_PARTS
