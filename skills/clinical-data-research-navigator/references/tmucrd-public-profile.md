# TMUCRD Public Profile

> Warning — public source snapshot: This file is not a data dictionary, DDL,
> availability promise, or query specification.

## Descriptive scope

Public sources describe the Taipei Medical University Clinical Research
Database (TMUCRD) as a collaborative research database derived from the
electronic health records of three affiliated hospitals. Use that description
only to explain the resource's research context and broad capabilities.

The 2024 peer-reviewed publication describes a multi-hospital longitudinal
resource with public data categories that include demographics, encounters,
diagnoses, medications, procedures, and clinical measurements. It also
describes linkage with cancer-registry and death information. These categories
do not imply that any particular field, linkage, or cohort is available for a
current request.

The 2024 publication reports a historical source window of 2004–2021 and a
historical scale above 4.15 million patients. Treat both figures as a
publication-year snapshot, not as current coverage, availability, or a release
guarantee.

## Standards direction

The 2024 publication describes work toward common-data-model alignment,
including an OMOP direction, to support consistent multi-domain research.
Describe this as a standards-alignment direction reported by the publication.
Do not infer a current model version, physical implementation, identifier, or
mapping from it.

## De-identification and governance

Public descriptions present the resource as governed research data prepared
with de-identification and access controls. State this only at a high level.
Project approval, permitted use, current access, and disclosure controls must
come from the responsible institution for the specific study. This profile
does not classify fields or authorize data access.
